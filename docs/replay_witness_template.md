## 判定标准

- **PASS**：六案例 × 六数据面 = 36 格全部有数据、行数 > 0、无异常缺口
- **FAIL**：任一格数据缺失或行数 = 0（需记录原因：迁移未覆盖 / API 回填失败 / 源本身无数据）
- **条件 PASS**：缺口可由 lovetrade 历史迁移补全（标记为"待迁移覆盖"）
