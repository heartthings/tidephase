## 0. 一句话定位

用「**题材是舞台，情绪是推力**」一个核心，串起从市场认知到下单执行的完整闭环。
**复杂性是认识论，不是模板**——体系给的是「判断顺序和规则」，不是预测点位的公式。

---

## 1. 认识论层（土壤）：为什么这么做

| 概念 | 含义 → 对操作的指导 |
|---|---|
| 复杂系统 + 幂律分布 | 少数股票贡献大部分涨幅（10% 股票贡献 80% 涨幅）→ **只做幂律顶端的票，放弃杂毛** |
| 正/负反馈回路 | 主线上涨 = 正反馈闭环（龙头连板→跟风→扩散→估值升）→ **做正反馈初期，止盈在衰竭期** |
| 涌现性 | 个股资金→板块多股联动→板块效应涌现→主线确立→结构行情 → **抓涌现性确定结构机会** |
| 混沌与分形 | 大局可认知（主线/情绪），细节不可预测 → **用规则（仓位/止损/情绪规则）对冲不确定性** |
| 自组织与临界 | 临界信号（极致缩量、筹码集中、情绪冰点/狂热）→ 一根大阳/阴触发变盘 |

**一句话**：不要试图赚市场所有的钱，只赚正反馈初期、幂律顶端的那一波。

---

## 2. 主干层：题材 + 情绪

- **题材是情绪的载体，情绪是题材的生命力。**
- 题材确立 → 情绪发酵 → 情绪演变 → 行情呈现。

这是整个体系的两根支柱，往下所有环节都在给这两个字提供「可执行的判断」。

---

## 3. 题材研判（舞台）：找对舞台

### 3.1 题材生命周期（高度是温度计）

| 阶段 | 高度特征 | 动作 |
|---|---|---|
| 聚集 | 涨停家数聚集、高度停 1 板 | 试错，看谁先 3 板 |
| 发酵 | 高度突破 3 板 | 启动，可介入 |
| 高潮 | 高度 6 板+ | 准备撤退，不追 |
| 退潮/冰点 | 断板、涨停家数回落、高位补跌 | 降仓观望，问题材有无持续性 |

### 3.2 真舞台 vs 大标签口袋

- 看**涨停原因原文**（zt_pool.reason），找「**更紧的一截**」。
- 例：低空经济 454 只是大标签 → 飞行汽车 93 只才是真舞台；人工智能 1532 只 / 并购重组 757 只是大口袋。
- 判据：涨停家数聚集在具体小板块 + 原因原文真写这个题材，才是「舞台成立」。

### 3.3 原因消息 vs 盘面结果

- **原因消息**（打在题材上的订单/政策/产业）= 新鲜度来源。
- **盘面结果**（「概念股拉升」「多少股涨停」）= 不是原因，不构成新鲜度。

### 3.4 题材来源 & 切换

- 来源：想象力、创造性、可信消息、全球共舞。
- 切换四层面：**逻辑**（原题材利好兑现、新题材有大消息）＋ **资金**（原流出、新流入）＋ **板块**（原走弱、新走强）＋ **核心**（原中军分歧、新核心崛起）。

## 4. 情绪研判（推力）：把握节奏

### 4.1 情绪是温度计

情绪 = 题材的生命值，在**冰点 ↔ 火热**之间每日移动。本质看「市场有多少愿意继续做多的力量」。

- 计算维度：今天涨停多少、昨日涨停今日表现、昨日连板今日表现（对应 `sentiment_daily` 的 limit_up / dbcgl / dbyll）。
- 情绪周期：**火热 → 分歧 → 退潮 → 冰点 → 复苏**。

### 4.2 量化力量级规律（本次回测验证）

| 规律 | 数据 | 含义 |
|---|---|---|
| 强者恒强 | 首板→二板 15%，二板→三板 30%，三板→四板 45% | 高度越高情绪越强 |
| 弱市出妖股 | 全市场涨停<30 只时，首板二板延续率约 20% 反而最高 | 冰点涨停股 = 资金抱团真龙头 |
| 题材聚集度 = 舞台强度 | 孤板 13% → ≥6 只爆发 16.8% | 有板块效应的首板更易延续 |
| 适度聚集优于过热 | 3-5 只走三板 33% > ≥6 只 28% | 板块过热易次日分歧 |

### 4.3 竞价判断情绪基调（五看）

1. 看连板高标（风向标）；2. 看炸板股承接；3. 看强势中军承接；4. 看涨/跌停数量（一字多=强）；5. 对比近期情绪（综合判断）。

### 4.4 推力 = 主力资金

- `fund_flow_stock.main_net_inflow / main_net_pct`：主力净流入、净占比。
- 涨停家数聚集 + 主力资金刚起来 = 推力启动；高度还在但推力变薄 = 撤退信号。

### 4.5 资金行为：预期你的预期（本次回测验证）

资金会预判大家的预判：一致看多时，先把次日涨幅在跳空里兑现；一致恐慌时，等卖压释放完再反手买。两类都有可计算的条件，也都有边界。

| 场景 | 条件 | 结果 | 边界 |
|---|---|---|---|
| 上涨端兑现 | 放量涨≥3%（量≥1.5x） | T+1 -0.24%/42.0%，低于基准 -0.02%/47.1% | 次日高开≥0.5%：T+1 +1.94%，但开盘买→收盘仅 +0.02%/44.0%，冲高回落 48.2% |
| 首板追高 | 首板+次日高开（剔一字） | T+1 +3.21%/67.9%，开盘买→收盘 -0.57%/44.8% | 高开后收跌：开盘买→收盘 -4.51%，冲高回落 88.0%，持到 T+2 -4.73%/胜率 18.0% |
| 周五发酵 | 周五首板+周一高开 | T+1 +4.00%/74.2%（周内最强），开盘后 -0.30% | 要等 T+2 才 +0.79%，追高首日仍负 |
| 下跌端反手 | 3日跌≥8% + 量比≥1.2 | T+1 +0.57%/55.7%，累计 T+2 +1.08% | 缩量阴跌（量比≤0.8）：T+1 -0.26%，累计 T+3 -1.14%/41.3% |
| 真正恐慌 | 上述 + 收在最低 20% | T+1 +1.04%/63.0%，累计 T+2 +1.68%，累计 T+3 +1.58%/63.6% | 盘中已拉回（收在最高 60%）：T+1 -1.13%/31.0%，累计 T+3 -1.84% |
| 周五恐慌 | 3日跌≥8%+放量+周五 | 周一 -1.01%/45.3%，周二 +1.47%/63.7% | 买点在周一杀跌之后，不在周一开盘 |

三条口述之外的边界：

- **先发生的反转不是买点**：盘中已经拉回的「恐慌」样本，次日反而亏——反手买已在当天发生，次日买的是第二棒。
- **「跌得多」不等于「跌出恐慌」**：深跌<-30 只有 +0.13%/47.3%，-15~0 位置最好 +1.32%/65.0%，强势>15 无超额（+0.00%/48.3%）。情绪 60-100 家涨停时 B3 为 -1.01%/37.2%，火热>100 为 -0.99%/29.0%；冰点<30 的 +3.17%/91.6% 仅 8 个交易日，属相态级证据。
- **级别不同**：个股「10 点前跌≥2% → 10 点后」+2.12%/70.8%（12 日样本），上证同条件 8 次仅 +0.12%/37.5%、全天 -0.53%，个股规律不能直接套大盘。

对应宪法：F-024（上涨端）、F-025（下跌端）、F-026（边界）。

## 5. 选股（在舞台内选演员）

### 5.1 个股五要素

板块联动 · K 线位置（平台横盘/中位/低位/高位）· 量能（上涨放量、下跌缩量）· 日内分时 · 筹码+均线（低位密集、多头向上）。

### 5.2 主线做票三角色

- **先锋**：打高度、拉情绪（一进二/横盘或深度调整完成，不追高标）。
- **中军**：承接大资金、分歧时稳盘（不破五日线）。
- **补涨**：情绪未散时套利（畏高资金的选择）。

### 5.3 量化形态信号（首板 T+1 命中率，<300 亿）

| 信号 | 命中率 | 倍数 |
|---|---|---|
| 低位放量 + 光头阳线（60日跌>20% + 2倍量 + 涨>5% + 上影<1%） | 6.99% | 5.1x |
| 低位放量启动 | 4.60% | 3.4x |
| 急跌（3日跌>10%） | 2.53% | 1.9x |
| 横盘放量上影线（试盘） | 2.89% | 2.1x |
| 缩量堆积（单独） | 0.48% | 0.36x 无效 |

### 5.4 两条关键判断

- **位置第一权重**：是否深跌后的低位，权重高于盘口动作。
- **上影线方向性取决于位置**：横盘蓄势里放量上影线 = 健康试盘（2.89%）；低位深跌后带长上影 = 负信号（2.41%），低位要「光头阳线收在最高」（6.99%）。

### 5.5 市值分层

流通市值 <300 亿；100-300 亿是高度延续最优区间，≥300 亿明显跑输。

## 6. 执行层：仓位 + 克己

- **生命周期节奏**：聚集期试错 → 发酵期介入 → 高潮期撤退 → 退潮期观望。
- **控制仓位**：固定仓位进去就别乱调；加仓是为扩大利润，不是摊薄亏损。
- **克己**：知行合一，不追高（追了就是飞刀），错过就等下一次；理智看待错误，及时止损防止不良情绪蔓延。
