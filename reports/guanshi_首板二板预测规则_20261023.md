# 观势数据层 · 首板与二板预测规则（题材+情绪框架）

> 生成日期：2026-10-24
> 定位：首板/二板是判断题材与情绪周期的「温度计」，不是打板选股目的。题材是舞台，情绪是推力。

---

## 0. 一句话框架

题材是舞台，情绪是推力。**首板 = 题材「开始聚集」的信号；二板及以上 = 题材「发酵/启动」的确认。** 规则服务于「判断题材处于生命周期哪个阶段、值不值得做板块仓位」，而不是「选哪只票明天涨停」。

---

## 1. 三层判断顺序

1. **舞台层（题材）**：哪个题材在聚集？是不是「真舞台」？
2. **推力层（情绪）**：主力资金、放量、情绪温度是否刚起来？
3. **温度计层（高度）**：题材内个股能否从首板延续到二板/三板？

---

## 2. 首板规则（题材「聚集」信号）

### 2.1 舞台层：判断哪个题材正在聚集、是否为真舞台

- 涨停家数聚集在「更紧的一截」具体板块（如飞行汽车 93 只、版权 38 只），而不是大标签（人工智能/并购重组）
- 涨停原因原文真的写这个题材（真舞台），而非标签挂名（口袋）
- 有「原因消息」打在题材上（订单/政策/产业），而非「盘面结果」（概念股拉升/涨停家数）
- 主力资金净流入/净占比刚起来（推力启动）

### 2.2 个股层：题材内谁容易出首板（形态信号）

| 信号 | 命中率 | 倍数 |
|---|---|---|
| 低位放量+光头阳线（60日跌>20% + 2倍量 + 涨>5% + 上影<1%） | 6.99% | 5.1x 最强 |
| 低位放量启动（同上，不要求光头） | 4.60% | 3.4x |
| 急跌（3日跌>10% 或单日跌>6%） | 2.53% | 1.9x |
| 放量+上影线试盘（2倍量 + 上影线>2% + 涨0-7%） | 2.89% | 2.1x |
| 缩量堆积→放量试盘（近20日缩窄幅 + 当日2倍量涨3-7%） | 2.18% | 1.6x |
| 平台突破 | 1.82% | 1.4x 弱 |
| 缩量堆积（单独，无放量试盘） | 0.48% | 0.36x 无效 |

前提：流通市值 <300 亿。

**关键认知**：「上影线」的方向性取决于「位置」——横盘蓄势里放量上影线是健康试盘（2.89%）；但低位深跌后带长上影是负信号（2.41%），低位要「光头阳线收在最高」（6.99%），代表主力决绝拉升。缩量堆积单独无效（0.36%），作为前置条件也是负贡献。

### 2.3 量能维度（首板/二板都必看）

个股级：
- 量比 = 当日量 / 近5日均量：>2 为异动，2-5 属试盘/启动，>8 警惕对倒或见顶
- 换手率：5-15% 为健康活跃，<3% 无关注度，>15% 警惕高位筹码换手
- 缩量程度：前期量能萎缩越极致（缩到前均量的 0.5-0.8），后续放量越有爆发力

板块级：
- 板块成交额环比：题材爆发当日板块成交额环比明显放大 = 增量资金入场、确认推力
- 涨停家数聚集 + 板块放量 = 真启动；家数聚集但缩量 = 存量博弈、易回落

### 2.4 首板次日：涨幅在跳空里，开盘追高是负期望

首板之后的次日，一致预期先在开盘兑现，开盘之后买入的人接的是兑现盘。

| 样本（<300亿） | n | T+1均涨/胜率 | 开盘买→收盘 | 冲高回落 |
|---|---|---|---|---|
| 首板全部 | 13,096 | +1.29%/54.1% | -0.24%/44.4% | 48.7% |
| 首板+次日高开 | 7,001 | +3.52%/69.3% | -0.54%/42.9% | 59.6% |
| 首板+次日高开（剔一字） | 6,709 | +3.21%/67.9% | -0.57%/44.8% | 62.2% |
| 首板+高开后收跌 | 3,506 | -1.03%/38.6% | -4.51% | 88.0% |
| 周五首板+周一高开 | 1,362 | +4.00%/74.2% | -0.30%/44.3% | 57.3% |

- **次日上涨是真的，但涨幅不属于开盘买入者**：首板+高开的 T+1 均值 +3.21%，几乎全在跳空里；开盘后到收盘是负的。
- **追高被套的具体形态**：高开后收跌的样本，当天开盘买→收盘 -4.51%，冲高回落率 88.0%，持有到 T+2 收盘 -4.73%、胜率仅 18.0%——当天亏 4.5% 之后第二天再亏，就是「不舍得割」的由来。
- **周五发酵最极端**：周五首板+周一高开 T+1 +4.00%/74.2%（周内最强），但开盘后仍 -0.30%，要等 T+2 才有 +0.79%。
- **例外**：普通放量上涨（非首板）的周五样本，周一开盘后仍有 +0.47%/51.8%，不能把「首板追高负期望」外推到所有票。

对应宪法 F-024。

## 3. 二板规则（题材「发酵」确认信号）

### 3.1 高度延续的量化事实（温度计读数）

| 阶段 | 延续率 |
|---|---|
| 首板 → 二板 | 约 15% |
| 二板 → 三板 | 约 30% |
| 三板 → 四板 | 约 45% |

- **强者恒强**：越高板情绪越强，晋级率翻倍递增。

### 3.2 什么条件下首板更容易延续到二板

- **题材聚集度越高越易延续**：孤板 13% → ≥6 只爆发 16.8%
- **情绪冰点期延续率反而最高**（全市场涨停<30 只时约 20%）——冰点涨停股是资金抱团的真龙头
- **适度聚集优于过热**：走出三板时「3-5 只聚集」(33%) 高于「≥6 爆发」(28%)，板块过热易分歧
- **流通市值 100-300 亿最优**，≥300 亿明显跑输
- **量能承接**：二板当天量能未大幅萎缩（量比仍>1）说明承接良好；缩量一字则锁定、放量分歧需谨慎

### 3.3 判断题材是否「启动」（从聚集到发酵）的关键问句

- 谁先走出 **3 连板**？（聚集 → 发酵的确认线）
- 次日涨停家数有没有掉？（聚集是否持续）
- 龙头主力资金还在不在进、板块量能还放不放？（推力是否延续）

## 4. 操作节奏（按生命周期定位）

| 阶段 | 高度特征 | 动作 |
|---|---|---|
| 聚集期 | 涨停家数聚集、高度停 1 板 | 试错，看谁先 3 板 |
| 发酵期 | 高度突破 3 板 | 启动，可介入 |
| 高潮期 | 高度 6 板+ | 准备撤退，不追 |
| 退潮期 | 断板、涨停家数回落 | 降仓观望 |

## 4.1 其他需一并考虑的因素

- 量（量比/缩放量程度/换手率/板块成交额环比）——见 2.3
- 价（位置高低、涨幅是否温和）
- 时（封板时间早晚、连板高度）
- 空（流通盘大小、市值档）
- 题材与情绪（聚集度、生命周期、两类情绪、主力资金）

## 4.2 恐慌后的买点（与首板/急跌信号衔接）

「急跌」是首板形态信号之一（2.53% 命中率），但急跌之后能不能买，取决于量：

| 条件（3日跌≥8%） | n | T+1 | 累计 T+2 | 累计 T+3 |
|---|---|---|---|---|
| 放量（量比≥1.2） | 14,075 | +0.57%/55.7% | +1.08% | +0.81%/56.2% |
| 放量 + 收在最低20% | 8,640 | +1.04%/63.0% | +1.68% | +1.58%/63.6% |
| 缩量（量比≤0.8） | 29,709 | -0.26%/47.0% | -0.73% | -1.14%/41.3% |
| 放量 + 盘中已拉回（收最高60%） | 2,029 | -1.13%/31.0% | -0.64% | -1.84%/32.7% |

- **分水岭是量，不是跌幅**：缩量阴跌没人抛完，资金不来；放量恐慌才是「抛售完反手买」。
- **当天收在最低 20% 才是真恐慌**；盘中已拉回说明反手买已发生，次日买的是第二棒。
- **周五恐慌的买点在周二**：周五放量恐慌样本，周一 -1.01%、周二 +1.47%/63.7%；周一还有一次杀跌，别在周一开盘接。
- **位置**：-15~0 最好（+1.32%/65.0%）；深跌<-30 只有 +0.13%，强势位无超额——「跌得多」不等于「跌出恐慌」。
- **级别**：个股层面「10点前跌≥2% → 10点后」+2.12%/70.8%，上证同条件仅 +0.12%/37.5%，不能套大盘。

对应宪法 F-025 / F-026。
